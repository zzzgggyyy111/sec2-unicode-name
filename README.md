攻击者用一个看起来一样的用户名注册，系统认为是新用户，仿冒账号就这么建了出来：标识必须按统一形式归一化后再比较；同形字符必须被识别或拒绝；大小写折叠必须按固定规则且只做一次；零宽字符与控制字符必须拒绝；归一后冲突必须报错而不是后到覆盖；批量校验各标识独立。不变量：视觉相同的两个标识不会同时存在；同一标识两次归一结果相同。
